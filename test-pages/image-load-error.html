Image load error

Long-press each target. The viewer should open, then close with its fade, and the console should show "Failed to show the image" with the url.

1. Link to a missing image

The link looks like an image by its extension, but the file doesn't exist.

missing-image.png

2. Broken image

The image is broken on the page too, but still has a size to press.

3. Image that works on the page only

The page shows the working 1x or 2x candidate, but the viewer opens the largest one, 4x, which doesn't exist. On a display above 2x, the page picks the 4x candidate too, and the image is broken like in 2.

4. Corrupt image

A link to a PNG that is only its file signature, so it fails to decode. Works without a network and from a file url.
